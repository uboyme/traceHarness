## 方法与边界

从关闭的原 SQLite 读取唯一失败 Attempt，按 Stream、snapshot seq、Step、Turn、dispatch fingerprint 绑定原请求，并核对 ModelRequest 往返与指纹。冻结当前源码、原数据库摘要、请求摘要和一次调用上限。复用原 `record_http` / `analyze_body` 及现有获准连接加载器，不读认证头或导出环境值；直连、60 秒超时、一次调用、无重试，不执行任何返回 Tool。

原始响应保存在本机忽略目录，不成为默认生产日志或第二事实源。原数据库与题目没有改动，未重跑完整 Product。
