修复模型输入的说明矛盾，不改搜索算法、排序、来源授权或事实源。Composition 从当前 generation 的实际工具表生成来源导航；Context 明确参考正文与 Tool Output 的不同交付位置，搜索页旁说明字面匹配和字段范围。拒绝反馈仍沿原 Policy，不猜替代工具、不修改评测 SourceOnly。

没有新存储、兼容层、语义索引、模型专用规则或测试答案默认值。因冻结呈现改变，按 [ADR-0063](../adr/0063-source-navigation-and-delivery-semantics.md) 切到 Session 12 / Context 11 / active-reference-policy-v7 / context-json-v11；旧 Session 1–11 明确拒绝。没有删除、改写或迁移用户数据，旧记录可由当时源码读取，新会话需要新数据空间。

## 无答案反例：没有解决，不能隐藏

正例跑完后，使用同一源码另冻结 [两对无答案反例](../validation-data/active-retrieval/source-guidance-negative-01/summary.json)，没有中途调提示或删题。

- 修复版 Skill 仅读简短说明便宣布整本手册没有规定；基线只对可见内容作有限表述。
- 修复版输出题未调用搜索便从预览宣布原输出不存在所问编号。基线实际对完整输出搜索了一个相关词并得到无命中，但回答夸大了已检查的其他词语和总行数。

因此修复版两个负例仍失败，存在停止过早及结论范围不受证据约束的问题。单次对照不能证明稳定回归，也不能把正例 6/6 当成整体改善保证；两组结果分开保留，不择优拼出发布分数。

本轮总共 16 条真实旅程、84 个请求、434,585 reported total tokens。完整 AR-D 成绩仍是 grid-05 的 45/72，发布状态不变。
