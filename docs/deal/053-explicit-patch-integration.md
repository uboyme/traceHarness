# 053：WC-3 显式 Patch 整合与回执

2026-09-13。继记录 052 后按用户连续授权实施。未提交、推送或发版。

## 当前结果

只有显式启用 patch_author 的 multi 主方增加原文读取、明确整合、只读对账三个工具。原文分页必须实际进入主方冻结请求；Patch id、预览或最后一页不能冒充全文。原 Artifact/CAS 与同源 Git 对象相互核验，原 WorkspaceService 拥有身份检查、文件发布和补偿，原 Tool Effect 保存冻结请求、操作身份和逐文件回执。没有另建账本、调度器或自动审批。

例如助手改 A、主方改 B，主方读完后可以明确整合 A 并保留 B；若主方已改 A，则报告冲突并保留主方内容。第一文件已写、第二文件失败时，只在第一文件仍等于本次后像时撤回；第三方内容和不明状态保留。取消须等发布、补偿和原 Effect 回执收敛。

## 边界

精确比较实际字节；不自动处理 checkout 换行/过滤器差异，不支持特殊文件，Windows 无法证明的执行位变化拒绝。源 Git 对象不可用明确失败，不联网补取。多文件不承诺全目录原子性，也不抵御宿主同权限恶意进程。全文可见不等于模型理解，整合不等于功能正确；最终固定验证和人工 Promotion 保持独立。
