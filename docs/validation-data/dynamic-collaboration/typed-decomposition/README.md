# DA-7 typed decomposition 真实实验

本目录保存 DA-7 四轮真实 `qwen-plus` 小样的精简证据。每轮都只包含三类冻结场景：可独立调查、紧耦合状态链和简单读取。原始 Session、Effect、请求、Budget 与 Workspace 记录保留在本机忽略目录；这里不保存密钥、请求正文或绝对路径。

| 轮次 | 真实调用 | 合法决策 | `separable` | 助手 | 任务成功 | 行为通过 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 6 | 0/3 | 0 | 0 | 0/3 | 0/3 |
| 2 | 18 | 2/3 | 0 | 0 | 1/3 | 1/3 |
| 3 | 23 | 2/3 | 0 | 0 | 1/3 | 0/3 |
| 4 | 21 | 2/3 | 0 | 0 | 1/3 | 1/3 |
| **合计** | **68** | **6/12** | **0/4 个预期可拆场景** | **0** | **3/12** | **2/12** |

`correct_typed_choices=5`：六次合法决策中，五次与冻结期望相同；另一次把可拆场景选成了 `local`。第一轮暴露的 `local` schema 过严问题随后修正；后续又增强了通用字段说明、决策规则、Tool 排序和两次有界修复，但最终一轮仍没有出现 `separable` 或助手。

所有 12 个 trial 的 Budget 都收敛，关闭后活动 Workspace 均为 0。实验没有运行 baseline、语义裁判、旧 72 题、全量测试或 L2；这些数字只回答“这个候选是否值得接入”，不表示统计显著性或模型普遍能力。

冻结合同规定真实模型仍不能正确分类时必须撤回生产接入。因此候选代码、Tool 和 Policy 接缝已删除，现有 `single` 和原 `adaptive` 行为保持不变。下一步可以单独研究“普通工具可见前的专用决策界面”，但它只是待冻结的设计问题，不能把本次失败写成已实现能力。
