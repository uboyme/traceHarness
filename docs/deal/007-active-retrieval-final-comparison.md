# 007：主动检索最终真实对照

状态：已完成一次固定题库真实对照、逐项审阅与独立重放。基线 20/72 → 当前 51/72；原发布门槛仍为 NO-GO。生产代码未再修改。

## 1. 本轮范围

用户接受当前实现，要求最后复测改善幅度，同时检查是否造成无必要的检索。本轮冻结生产实现，仅执行真实对照、证据审阅与离线重放，不根据本轮结果继续修改提示或协议。

- 主网格：[grid-06](../validation-data/active-retrieval/ar-d-grid-06/frozen.json)。原 24 道自然问题 × 三组种子，每臂 72 条；问题、生成材料、模型、预算及原验收门槛与 grid-05 相同。
- 基线为原 `a54d431`，候选为本轮开始时的完整工作区源码快照。基线已有原文读取及 Tool Output 搜索，缺少新增的 History / Memory / Skill 主动搜索。比较反映累计修复，不能归因于最后一处呈现修改。
- 两臂同为 `openai-compatible/qwen-plus`，复用授权配置加载器；不输出密钥，不修改用户会话。模型标识不意味着远端实现永久不变。
- 每个已关闭用例只执行一次，保留连接失败、耗尽步骤及答错记录；两批各最多两个 worker。详见[冻结执行安排](../validation-data/active-retrieval/ar-d-grid-06/execution-schedule.json)。
- 原题已用于此前诊断，本轮是固定题库回归测量，不是新的独立留出集，也不估计通用成功率。

## 2. 防止无必要搜索的独立对照

[四个日常问题](../validation-data/active-retrieval/ar-final-controls-01/experiment.json)分别为打招呼、礼貌改写、简单加法和复述用户刚提供的数字；两臂均提供无关的已选 Skill，检查实际回答和工具调用。它们不加入 72 题，也不使用原网格的自动暂定得分。

不要求每道题搜索，更不要求读遍所有内容。问候和基于当前消息的任务可以直接完成。对尚未读取的来源，模型可说明目前没有证据；但仅根据 Skill 主题推断整份正文不存在某项事实，仍不能当成已验证的事实。本轮保留原来的范围与证据判定标准。

## 3. 判定与统计约定

正例同时检查答案、归属及成功模型请求中实际存在的源证据；负例检查结论是否符合真正检查过的范围。接口返回成功和模型自称读完不构成证据。搜索片段若已经包含足以回答的原始事实，不为了形式额外强制一次读取。

主成绩使用固定 72 分母，连接失败单列。另给出两臂都未发生执行错误的成对子集，供辨别网络影响；不把这个子集冒充完整成绩。步骤、检索读取次数、延迟和 Provider 报告的用量分开统计，未知用量保持未知，准备会话与目标问答分开。

逐项人工语义审阅后，分别用每臂冻结源码从 SQLite 只读备份重开会话，核对事件导出、冻结请求、不变量及 Attempt 收敛；离线重放不调用 Provider。不运行全量 pytest、L2–L4、打包安装或发布门禁，不提交或推送。

## 6. 具体收益与剩余问题

- 工具输出的诊断分组口令题：当前三组材料均 `search_tool_output` 后读附近，得到正确原文；基线两条耗尽步骤、一条连接失败。任务只问自然问题，没有提供工具操作步骤。
- Skill 的章节、资源块读取已能把实际正文交给下一次模型请求；基线常拿到目录后仍缺正文。累计收益包含控制回执及导航说明修复，不能全算作“新增了搜索”。
- 当前三条“初始 Memory 目录遗漏呼号”的题仍未查到目标，连续读背景项后停下。
- 当前三条 Skill 无答案题仍根据目录、主题或一个简短章节推断整份手册没有；两条已完成的 History 无答案题仍只读局部便作全局否定。
- 当前三条归档核验代号题仍把 `digest` 当业务代号；一条英语输出题仍把退出码当业务代号；故障代号题两条错误认为没有、一条连接失败。定位入口和范围说明改善了部分情况，没有消除模型语义误判。

保留现在的按需查找策略。资料主题不相关时可以不继续查，回答应说明证据范围；不能把“不值得再查”的判断当成“已经证明正文不存在”。同样不把有足够原始片段却没额外 read 的答案判错。
