# WC-4 工具导航与 Patch 分页说明修复

2026-09-13，用户授权开始修复。保留现有未提交改动和五轮原始验收记录，不新增真实模型调用。

## 根因与所属层

记录 060 的冻结请求已经提供实际工具清单，但 session/context_input.py 的通用导航和 supervision/patch_integration.py 的说明又提到未提供的输出工具。原 Patch count 默认 2000、最大 4000，按 Unicode 字符切片；公开 schema 却没说明这些语义。这是说明与实际能力的对齐问题，不能用扩权或增加调用预算解决。

## 当前实现

- 通用导航不枚举未必存在的工具，明确以当前工具列表及参数为准；来源 read_action 同样须核对实际列表。
- Patch 工具公开字符单位、offset 从 0 开始、默认 2000/最大 4000、next_offset 为 null 表示完成，首次只需 artifact_id。实现与 schema 共享原有数值，仍允许模型自行选择页大小。
- 保留输出时仅使用当前提供的读取能力，或缩小同一页；无法取得正文报告限制，不猜测新工具名，不把预览当全文。
- 完整原文覆盖、目标前像、所属身份、显式整合、取消回滚、预算与人工 Promotion 保持。

详见 [ADR-0075](../adr/0075-tool-guidance-and-context-renderer.md)。确定性 Context renderer 更新为 v13，Context 13 / Session 15；旧会话拒绝直接恢复，需要新数据空间/新会话。旧日志不改写或删除，没有兼容分支。
