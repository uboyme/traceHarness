# ADR-0063：来源导航与交付语义

日期：2026-09-09。状态：已实现，真实对照见修复记录。

## 问题

History、Memory、Skill 通过回执请求下一 Step 的参考正文，Tool Output 在工具消息中直接交付。
旧参考包把“回执后正文缺席”泛化到所有来源，工具输出题也收到空参考数组与这条说明。
搜索结果的字面匹配范围分散在系统提示与工具描述中，易被解释成整个资料不存在。

## 决定及所有权

- Composition snapshot 使用当前 generation 捕获的 Tool schemas，生成来源、搜索范围、暴露工具和交付位置表，冻结进原 system_prompt。只解释现有宿主工具，不发现插件、不推断来源存在或工具获准，不调用 Policy.check。
- Context renderer 明确区分参考包与工具消息；空参考数组不表示 retained output 不存在。History/Memory/Skill 正文缺席规则不套用到工具输出。
- 搜索结果旁解释原来的忽略大小写字面子串匹配、fields、no-hit、source-unavailable 与下一页含义。查询算法、排序、来源集合、Reader、回执及授权规则不变。
- 不复制工具正文进 Context，不创建新的目录存储、缓存或事实源。AgentLoop 与 Continuation 不参与来源选择。
- 策略没有声明替代来源，不能从拒绝推断可用工具；本次不修改拒绝结果协议或评测 SourceOnly。

## 协议

参考包字节与预算派生发生变化，唯一当前协议切到 Session 12 / Context 11 /
`active-reference-policy-v7` / `context-json-v11`。SQLite、M3、原来源搜索/披露回执格式不变。
拒绝 Session 1–11，不迁移、不自动改写或删除旧数据；新会话使用新数据空间。
历史真实对照使用各自冻结源码独立重放，不能用新版 renderer 冒充旧请求。

## 验证与停止规则

检查实际派发请求中的工具表/导航一致、来源不可用及错误查询反例、预算、取消、旧协议拒绝和独立重放。
通过移除导航的进程内反向实验确认公开 Runtime 测试失败。真实六对自然任务保持相同模型、材料、预算及权限；保留所有失败。
这不是发布验收或模型能力保证，不以达到 66/72 为本次修复条件，不把小样本得分替代 grid-05。
