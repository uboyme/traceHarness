## 4. 混合检索的边界

exact 与 eligible BM25 保留。语义向量只能是已获准规范内容的可重建派生数据；资格过滤在评分和
top-K 前，查询与重放不能偷偷下载模型、访问外部向量库或读取最新事实改写旧证据。
显式模型路径、内容摘要、分词/池化/归一化与维度属于配置/索引身份，不使用某个测试模型作隐藏默认。
本地已有可供调查的 embedding 依赖和资产；是否完整、可运行和适合多语言仍须实测。

不能只在原 RRF 后面附加向量分数：还必须审查词面覆盖准入、覆盖优先排序与冻结来源证明，避免
零词面重叠的有效语义候选在准入时被全部丢弃。同条件比较要同时保留 exact/zero-hit/hard-negative/
scope 等关键类别以及延迟、索引规模、重建成本。达不到预定增益时如实报告并保持可选 lane 关闭，
不能把哈希词袋向量冒称为已验证语义能力，也不能降低原检索基准的成功线。

本轮 C3 筛查已完成：原 11 题当前 Runtime 复验达到原阈值，44 个 Context/dispatch 与 SQLite 核对
无重放或不变量错误。原语义题和新增中英文各四题用于四种预注册本地候选比较。最佳候选的新增英文
Recall/precision 为 0.25/0.25，中文为 0.25/0.125，未达每项 0.75；九题平均 Recall 增益为 2/9，
未达 0.25。其他候选同样失败；成本与原非语义要求通过。按本节规则保持 semantic/reranker 关闭，
不接入未合格模型，不改变生产协议。完整数据、首次对齐失败和限定验证见
[C3 验证记录](../validation-v0.9-stop-c-c3.md)。

C4 已对齐原失败的请求引用与指纹，当前 Adapter 与历史运行源码字节相同。固定 24 次真实重放有
21 次解析、3 次连接/TLS 中断；18 个工具参数为合法 JSON object，与 Adapter 输出一致。另一个
最小文本控制成功，22 份实际响应经原 Adapter 离线字节复算通过。没有确认的源码缺陷，不放宽 parser；
历史没有 HTTP body，具体非法语法仍未知，不能声称已修复原失败。结果与 53 项定向检查见
[C4 验证记录](../validation-v0.9-stop-c-c4.md)。C5 已完成，最终 Stop C 结果见 §5。
