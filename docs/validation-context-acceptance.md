# E3：超限说明与真实长任务验收

2026-09-09。实现完成，模型质量局限保留；不等于发布门禁通过。
决策见 [ADR-0060](adr/0060-audited-context-limit-feedback.md)，范围见 [执行合同](plan/TRACEHARNESS_E_AND_SEMANTIC_EXECUTION.md)。

## 1. 用户行为与事实来源

Line/TUI 不再只给 RequestTokenBudgetExceeded：显示输入估算、输入额度、输出预留、安全余量和完整分项，
显示本轮成功折叠/摘录/摘要及失败次数、记录的参考 token 排除数。摘要请求超限单独标识。
原异常只携带 Session/Turn/Step 定位；Chat reader 复用原请求证明，所有数字来自同一失败步骤的账本。
读取或来源证明失败时显示明细不可核对，不编造数字，不泄漏问题、工具结果或底层异常正文。
提示缩短输入、按模型实际容量调整原 Token 设置、另起一轮读片段或新会话；没有自动重跑副作用。
Ctrl+X 的最近已发送请求可能早于本次被拦请求，不把两者混成同一调用。

## 2. 定向与反向验证

- 六项专项：真实 Runtime 的本地硬拒绝、Line/TUI 显示、诊断失败、普通 Provider 失败不冒充超限、
  后续 Turn 不能篡换之前拒绝的计数、实际旧历史维护后的拒绝；最终 **6 passed in 3.07s**。
- 八文件主线及相邻集合 **198 passed in 67.23s**；TUI/optional/提示集合 **61 passed in 78.02s**。
  集合有重叠，不相加冒充独立测试数量。TUI 是真实 Textual 的 headless 交互验证。
- 临时删除 Line 超限分支，新显示测试按预期失败；临时用最后一次计量代替原 Step，
  后续 Turn 的不同计数会使原失败身份测试失败。恢复原字节后再通过专项，见 [reverse.json](validation-data/context-acceptance/reverse.json)。
- compileall、范围 Ruff、示例硬编码检查、diff check 通过；全仓仅收集 **3529 tests**，没有全量执行。

早期测试夹具缺 Store、Provider 身份及 TUI 构造字段时即失败，修正夹具后才进入生产路径；这些启动失败不算反向证据。

## 3. 真实整合路径

入口 `tests/live_context_acceptance/run.py` 使用原授权配置加载器和真实 Provider，所有数据在新目录，
不改用户配置或会话、不记录真实密钥。例子、随机值、额度和脚本都为显式测试夹具。

同一 Session 顺序执行：建立旧档案清单与近期约束；实际运行检查；工具返回后摘要旧历史；重启换题；
通过 History 原文找回第 037 项随机编号；执行另一个超大输出检查；关键词搜索后展开附近，核对两个随机字段；
再次重启换题；在真实模型响应已经返回、尚未交给 Runtime 的边界重复取消；随后新问题回答正常；
最终用大输入触发硬拒绝、显示明细，再 fresh reader 重放验证。取消由显式 Event Gate 同步，不用 sleep 猜时序。

两条完成旅程分别在 02 的 exit-0 和 03 的 exit-7；每条 10 回合（含取消与拒绝）。原检查各执行一次，
大输出检查也各执行一次。非零退出真实为 7，模型报告失败，没有重跑或修复。原日志不变、请求重建和不变量均零问题。
这两条完成旅程有 **40 Attempt**、已知返回 usage **498614 token**；不是“整次 02 通过”。

同口径只展开首次语义替换的旧历史，下一普通请求估算为 **14374→12740**、**14510→12905**。
这只是单请求占用变化，不代表总费用节省。硬拒绝分别为 **44064/16000**、**44759/16000** 输入估算/额度；
当前问题、原工具结果仍保留，未发超限的那条请求。之前的摘要步骤可能已经花费费用。

## 5. 真实边界

后续模型摘要多次使用无效 source_seq，另有一次列表形状不合法。原验证器拒绝替换并保留原文，
其后空间够时继续原历史、仍不够时硬拒绝。没有放宽协议、丢弃错误或声称摘要每次都成功。
模型也会漏执行新工具指令；03 明确执行顺序后通过，不代表自然语言质量已得到普遍保证。
01 的夹具把搜索已足够回答误当需要再展开，后续改为搜索片段外仍有证据需要核对，没有修改生产搜索逻辑。

取消验收针对真实响应交付边界，不能冒充远端请求中途被立刻打断。已有 HTTP Worker 收敛边界不变。
本地 token 是估算，不能保证与远端隐藏模板一致；未实现分批摘要或 Provider 超窗自动重试。
全量 pytest、L2–L4、Wheel/安装/发布门禁均未运行，未 commit/push/tag/release。
