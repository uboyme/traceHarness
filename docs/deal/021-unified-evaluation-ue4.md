## 本轮做了什么

本轮属于 evaluation 验收层，增加 tests/live_unified_evaluation 的显式 baseline、controls、reopen 驱动与辅助材料，
继续调用原 EvaluationRunner / RetrievalEpisodeEvaluator、Runtime、Reader、SQLite 和 Sandbox。
没有改生产 src、提示、工具描述、权限、评分器、预算或持久协议；源码身份保持
`35cf9d7e2f3815a0521bc5b059765afb9aad6d13eee5999d31e2be9c0508648e`。

baseline 跑冻结的 24 模板 × 3 组材料，每题一次；不重试、不把补测拼进原分母。
controls 准备四条普通题和四条来源竞争题，每条新建原 Runtime/Session/Store，
Memory 真批准、Skill 真装配、History 真对话后压缩、原 shell 通过现有固定 Docker 镜像执行一次。
目标轮允许四类参考工具，禁止工作区探索和重跑 shell；这是受控辅助实验，不是开放 Chat 的全部工具权限。
它不新增生产 evaluator 或评分生命周期，也不改变原 72 题的来源隔离条件。

凭据只由原配置加载器使用；原值不打印、不落盘，归档逐字节扫描实际凭据并递归检查 ZIP。
真实模型为现有 qwen-plus，禁用系统/环境代理发现，60 秒单次超时、无模型重试，主运行总期限 7200 秒。
没有入围候选，所以没有第二臂；原 UE-3 A/A 仍只作历史方差证据。

## 找到了哪些共性

| 观察 | 对应真实样本 | 后续实验线索，不是本轮已修复 |
|---|---|---|
| 首批 Memory 未给答案就停 | m-omitted 三组均读六条背景项，正文指向另一个批准记录，却不 search_memory | 首批目录不是完整检索；有可操作线索时继续找 |
| 输出元数据冒充业务值 | o-rephrase 三组返回 digest；o-nonzero 三组没取得正文故障码；o-english 一组回答 exit_code=0 | 区分内容身份、执行状态和正文业务字段 |
| 被拒后只口头说继续 | s-english/419 请求 directory 失败，最终承诺搜索但没有再调用；227 组却能继续搜索并成功 | 研究拒绝后的有效下一步，不先断言整个工具不可用 |
| 局部观察扩展成全域否定 | 三组 History 只见第 0、1 页且仍有下一页；Skill 从主题/导航 no-hit 推断整本不存在；两组 Memory 猜测未读项 | 否定结论与实际覆盖范围一致，不能靠强制调用次数评分 |
| Memory 取代问题指定的来源 | 辅助 Skill/Output 问题均误读 Memory；正确目录、工具确实在请求里 | 先判断来源是否适用，再判断它在该问题上的权威性 |

Memory 撤销题的 227 组读完六个可见项，没有使用被撤销值；是否足以断言项目级不存在仍需审阅模型可见的集合完整性，
不能利用宿主知道夹具内容的优势替模型补证据。三组 Output 负例均对原输出作完整字面搜索，无命中；
其措辞是否符合原负例 rubric 仍待审，不因 no-hit 自动通过，也不因少一次 read 自动失败。

这组结果没有证明唯一事实源或 Reader/Projection 失效。来源与版本仍由原领域解释，
错的是模型在部分问题上的选择、继续查找和答案归属。下一阶段可以据此冻结受限说明文本实验，当前不提前实现 AO。
