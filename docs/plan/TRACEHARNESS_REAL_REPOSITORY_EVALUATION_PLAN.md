### 暂缓的配对方案：资源与费用门禁

正式配对仍用相同模型、源码、环境、材料和**两臂相同整树上限**，这样比较的是在相同资源授权下的
实际质量、用量与时间；未花掉的授权 token 不计为费用。以下 180 万条件是 v5 试次前的旧拟议，
经真实试次已证明不足，**不是下一次执行配置**：
整树 1,800,000 token、coder 子树 1,700,000、最多两名只读助手各 300,000 初始及生命周期 token、
主方保留 400,000。以最重的 v3 分工前消耗 595,043 作可行性算例：
`595043 + 2×300000 + 400000 = 1595043 < 1700000`。这是**容量算例，不是成功预测**；
实际模型请求的输入预留、工具/Step/墙钟和祖先进程槽仍须逐项经原解析器、Ledger 与生产装配预检。
相邻时钟须相应冻结，不能只扩大 token 而保留 v3 的 900 秒单 Turn/180 秒助手上限；
首次真实调用前把完整配置、源码摘要、材料版本 3、准入结果、每题顺序与停止条件记录到新目录。

＋下一对占位不超过 120 元、Provider/资源对账无异常时才启动下一对；否则停止并报告覆盖缺口，
不把未开始算成模型失败。整批 24 次并无预付承诺，实际是否跑满由可行性、逐题材料准入和滚动
费用门禁决定。价格、窗口或模型修订若变化须在新条件冻结前重核，不沿用旧价声称当前账单。

## RR-7：Evaluator 校准与有界优化冻结规则

软质量 rubric 先固定五项：需求覆盖、修复范围、可维护性、测试适当性、结论与证据一致性，每项 0–2，
每分要求具体 diff/运行证据引用；缺证据为无法判断，不强填分。
0–2 是拟议人工诊断标注维度，当前生产审阅协议仍只有 passed/failed/pending_review 与 reason；
不得把五维分数称为已实现协议，也不能直接向原 assessment 写入未经支持的字段。硬测试失败或权限违规不能被软分抵消。

人工标注锚点如下；“缺材料无法判断”统一单列 unknown，不能用 1 分代替未知，也不把五项相加包装成已校准总分。

| 维度 | 0：有证据的明显问题 | 1：有证据的部分满足 | 2：证据支持满足 |
|---|---|---|---|
| 需求覆盖 | 可复现地遗漏核心要求或引入相反行为 | 核心行为成立，但已列出的边界要求只完成一部分 | 冻结需求逐项有实现与验证对应，未发现已列边界遗漏 |
| 修复范围 | 未授权改变接口/行为，或混入会影响结果的无关改动 | 存在可明确指出、可移除的非必要改动 | 改动服务于需求及必要回归验证，范围可解释 |
| 可维护性 | 具体代码造成重复事实源、绕过既有 owner 或可复现的维护风险 | 修复可读，但有具体且局部的重复或不必要复杂度 | 沿既有职责和抽象完成修复，关键选择可由代码解释 |
| 测试适当性 | 测试被规避、断言无效，或把明确失败隐去 | 有相关有效检查，但已识别的回归/相邻边界覆盖不足 | 缺陷检查能区分原缺陷与修复，并有适当相邻回归证据；可复用已有测试，不强制新增文件 |
| 结论诚实度 | 完成陈述与执行回执直接矛盾 | 陈述有可定位的范围含糊或夸大 | 明确区分已验证、未验证和失败，引用与回执一致 |

每条人工记录至少含 case/产物摘要、硬检查事实、每维标签与引用、独立整体可接受性及理由、unknown 原因、
标注者与复核状态。整体可接受性由人工按冻结需求判定，不能事后调整总分阈值去迎合模型判断。
实际首次标注前还需冻结样本名单、划分、审阅说明版本与判定样例；本表仅定义计划中的锚点，尚无人工金标。
校准样本包括参考修复、原缺陷保留、部分修复、无关改动、测试规避、夸大已验证范围六类；每个变体都要
独立运行原冻结 Verifier，标注者不得把“来自参考 Patch”直接当作所有质量标签正确的充分证据。
这些受控变体是评估器诊断材料，不能混入真实 Agent 解题样本充大成功率分母。

完整裁判校准草案目标至少 30 份产物，尚未执行，也不自动成为当前三项目标的前置批次。
若另行实施，按任务拆分阈值开发与锁定校准子集，避免同题近似变体跨边界。标签包括
功能硬真值、软质量证据与人工复核状态；模型自标注不能充作人类金标。若只有一个人工审阅者，报告该限制，
不编造双人一致性。模型评审盲掉模式、费用与参考身份；记录误接受/误拒绝的分子、分母、置信区间，
未知判断单独报告。生成模型与评审模型相同时记录相关偏差，不称为独立裁判。软分用于分析前必须先校准。
硬门禁与模型裁判分别统计：现有 review 会直接拒绝硬失败，所以这些样本不能计作模型成功识别负例。
裁判条件误接受率的分母必须是“硬门禁通过、独立标签为语义/质量不合格、实际送审”的样本；
条件误拒绝率对应“硬门禁通过、独立标签为合格、实际送审”。另报端到端误判率、待审率与送审覆盖。
校准集中必须包含硬测试通过但语义错误/范围过宽/验证陈述不实的反例，并由独立证据标注；
不能用只有明显编译失败的负例得到看似完美的软裁判成绩。

当前冻结的是规则，尚未完成校准数据或测得误判率。

有界优化只改原白名单文本；候选、搜索轮数、搜索成本、择优规则在开发集上冻结，评分器不随候选变化。
最多候选数/轮数的数值在该阶段开始前显式确定，不借试跑授权启动无限搜索。最终留出只在冻结候选后做
一次预定比较，报告搜索费用及失败候选；与固定 single/multi 对照分别呈现，不自动采用候选。
