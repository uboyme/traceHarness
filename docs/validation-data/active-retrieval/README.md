这里的题目、代号、材料和项目身份均为合成测试数据，不是生产默认配置。

Git 收录冻结配置、材料、逐题报告、人工判定、汇总、重放结果及诊断脚本。
当前合并成绩见 `grid06-direct-supplement/current-score.json`：55/72。
旧报告保留原分数与原 NO-GO，不用新结果覆盖原始运行。

原始 SQLite/WAL/SHM、Session/Effect 导出、实验源码 ZIP 和工具工作区保留在本机原相对路径，
不随源码发行。这些对象的文件名、大小与 SHA-256 见 `local-evidence-manifest.json`。
该清单是校验索引，不是可替代原事件的事实源；只有本地持有原始对象时才能重新打开这些历史实验账本。
报告中的原始文件路径在仅克隆源码的环境中可能不可用，不得据此宣称已独立重放。

新实验可用 `tests/live_active_retrieval` 的显式入口重新生成；真实 Provider 调用需明确授权和自有配置。
不要把凭据、用户会话或未审计的实验工作区加入此目录的版本控制。

`.gitattributes` 对本目录禁用换行转换，保持报告和摘要校验一致；捕获的 pytest 文本、XML 和 patch 原样保留空白，不为通过源码风格检查而改写历史输出。源码和其他文档继续执行正常 whitespace 检查。
