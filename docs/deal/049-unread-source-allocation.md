# 分工说明：未读来源可以成为调查任务

2026-09-13，承接[一次响应取证](048-planning-response-capture.md)中模型因未读规格而拒绝分工的观察。本轮只澄清说明，未追加真实调用，也未证明真实行为改善。

## 改动

只修改 `supervision/structured_collaboration.py` 的 `ALLOCATION_GUIDANCE`：区分“来源已定位但内容未读”和“来源不可用”。已有证据能定位相关来源，且属于助手获准只读能力时，可以把未知内容作为助手任务。主方应说明调查问题、来源、所需证据和局限，并保留使用调查结果的工作；不必先完成助手的调查再委派。

说明同时保留边界：未读不单独构成阻塞，但来源定位不等于访问授权或存在保证；不能编造来源，助手实际遇到拒绝、缺失、证据不足时应报告。没有绑定特定文件名、例题或模型，没有要求每次都委派读取规格。

原 `PLAN_REQUIREMENT`、字段校验、权限、预算、一次派发、停止/取消、只读工作区和收尾流程不变；没有把拒绝当成功或增加 local 选项。仍通过同一 `planning_guidance()` 进入规划输入与工具说明。它依然属于既有 AO 可编辑说明，不改变优化权限。

通俗例子（不是默认任务）：目录表明某份手册说明业务规则，主方尚未读它时，可以让助手提取规则及证据，再由主方实施。不能因为尚未读到规则，就先把它说成不存在。
