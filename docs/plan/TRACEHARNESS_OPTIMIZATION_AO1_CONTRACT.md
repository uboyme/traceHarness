# AO-1：人工候选进入原评估闭环

日期：2026-09-11。依据 [AO-0](TRACEHARNESS_OPTIMIZATION_AO0_CONTRACT.md) 与
[统一设计](TRACEHARNESS_UNIFIED_EVALUATION_AND_OPTIMIZATION_DESIGN.md)。本阶段不实现 AO-2 模型分析插件。

## 1. 入口和所有权

`evolution/optimization.py` 接收已配置的原 EvaluationRunner 模板、AO-0 合同、明确的开发观察与人工候选序列。
模板必须是两臂都为 current 的原 UE-3 配对计划；模型/Provider、材料、预算、重试、沙箱和比较条件全部冻结。
原 EvaluationRunner 提供重新绑定计划/输出的同类构造入口，仍静态装配原 evaluator。
原 comparison 提供只读 inspect 入口；写报告和 AO 判定都消费同一核验与比较计算，不另写评分器。

人工候选是显式的说明文本 edits、原因、目标失败类型和代价，不调用优化模型、不通过插件暗中装载代码。
AO-2 才把生成候选接到原 strategy/analysis 服务。本轮不新增 CLI 或默认配置，不修改 AgentLoop、检索算法、评分规则、权限或原持久协议。

## 2. 执行与记录

先核对合同与实际源码、benchmark/dataset/plan、完整选题及可改文字，再创建全新输出目录。
目录独占创建是唯一运行写入者的线性化点；无并行轮次、接管或自动冷恢复。
冻结合同、原输入与源码/材料摘要，人工序列与开发观察显式记录；不读真实 .env 或保存 Key。
每轮从已有原评估工件重新核对进度，经过 AO-0 decide_next 后，先记录整批 trial 预留和请求/提案，再运行。
admit_proposal 输出原 UE-3 patch，只有 candidate source 引用变化；输入文件位置仅作受核验的搬运。
原 EvaluationRunner/variant_execution 在独立进程执行两臂，所有原账本、准备成本、失败、取消、未开始槽位保留。

优化记录只是实验定义、提案、资源预留及指向原执行的回执；报告/计数从这些定义和原 comparison 重算，
不将可变 summary 当作业务事实。原 Session/Effect/Reader/Projection/CAS/Git 继续拥有执行证据。
只接受与该轮确切 patch、计划、基线、材料和试次匹配的实验。不能拿一个分数更高的别处运行替换。

## 3. 比较、待审与停止

三项比较门槛必须显式非空：最小净通过增量、最大 token 比例、最大工具调用增量。
完整证据/收敛通过，全部配对正式可判，零质量损失、三项门槛均通过且至少质量或成本一项改善，
才标为可交后续人工审阅的开发候选；仍不自动采用或声称已通过未见留出。
无改善或门槛不通过按连续无收益计数；缺证据、未知成本、执行不可判不伪装成质量退步。
pending_review 返回待审并退出本次调度，不把 provisional 或机器意见写成人工 judgment。
原 review/assess 可另外完成显式人工评分，新的离线优化检查可引用其精确文件和摘要重算结果；
这不会重跑原试次，也不自动恢复剩余候选。需要新执行时开新的显式实验；本阶段不承诺持久调度恢复。

达到任一 AO-0 限额、取消、总截止、无更多人工候选、非法来源/范围/证据或收尾未证明都停止。
重复/普通格式错误提案不运行模型；错误记录计入相应上限；来源/权限范围漂移直接停止。
总截止同时按初次计算的单调期限与 UTC 截止约束；单轮原计划预算不被候选改大。

## 4. 失败与取消

每次子执行都有原 owner；取消或总期限到达后，通知并等待同一原 worker 收敛，重复取消不能提前返回。
原错误与收尾错误保留稳定类别，不打印异常中的潜在秘密。原工件写入失败不冒充完成。
待审/停止都是实验结果，不执行安装、Git 提交、推广或发布；既有 L2/L3/L4 Wheel 主线不动。

## 5. 验证

用真实隔离子进程/原 Runtime/SQLite 跑人工文本候选，核对 candidate 的实际模型请求确有新文字，原版没有。
用原 Product/Git/沙箱/Verifier 的确定性任务验证正式无收益停止；用原检索旅程验证待审、离线审阅绑定及不重跑。
覆盖明确预算和轮次、重复/越界提案、冻结漂移、坏证据/错运行、未知用量、执行失败和重复取消；关键保护做反向验证。
确定性 Provider 与本地 HTTP 替身验证运行链，不冒充外部模型效果；本阶段不要求优化模型提案或新 72 题成绩。
执行 compileall、定向与相邻回归、collect-only、修改范围 Ruff、硬编码与文档/diff 检查；不跑全量、L2–L4、Wheel 或发布。
