## 4. 原因与解释边界

已验证：中文模型对四条中文改写的未知 token 都为 0；英文模型仍分别出现 10、10、6、7 个。
因此本次中文失败不能继续全部归因于分词器未知符号。真实相关材料在中文编码器的分数仍低于冻结 .6 门槛；
例如“现阶段在忙什么”对应阶段事实约 .431。语料本身混有中英文，两个单语言编码器取最大分数没有保证跨语言对齐。
这说明当前表示、字段组合与绝对阈值的组合未达到要求，并非证明降低阈值就一定更好。

另一个已知策略边界：只给词法空结果补候选，不能修正已有误召回或冗余；中文诊断题及阶段目录的情况仍保留。
候选不能借修正某道题绕开原词法合同；如果后续要改融合/重排或选别的多语模型，需另行冻结计划和门槛。
本次到九个候选测完即停止，没有看完分数再试 .4/.5 或修改例子。
