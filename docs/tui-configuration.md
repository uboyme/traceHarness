# TUI 启动与动态配置

在你要工作的文件夹运行：

```powershell
traceh
```

当前文件夹就是工作区，聊天记录默认保存在它下面的 `.traceh`。连接配置完整时直接进入聊天，**不再每次弹出配置面板**。

## 第一次配置模型

缺少连接配置时才打开简短向导：

1. 选择服务商和地区，程序填写对应地址。自定义服务才需要自己填地址。
2. 选择模型快捷项，或填写账号已开通的其他模型名称；不会自动替你选模型。
3. 填写 API Key。已有环境凭据可以复用；Windows 可勾选“记住密钥”。
4. 点击 **保存并开始聊天**。以后在其他工作文件夹运行 `traceh` 也可复用个人连接。

Windows 使用当前用户 DPAPI 加密保存密钥，密文与接入方式、服务地址和密钥变量名绑定，不保存到启动 JSON 或事件日志。其他平台当前使用环境变量、环境文件或临时密钥。系统存储不可读时明确提示，不明文兜底。个人默认只保存连接信息和最大步数，不把项目目录、插件或项目权限带到其他目录。

服务商快捷项和模型快捷项不是账号可用性验证，本地检查不会调用真实模型。地址来源与测试结果见 [简化启动验证](validation-tui-simple-start.md)。

## 新对话、继续对话和项目归属

- 默认直接开始新对话；聊天中输入 `/new` 再开一段。
- 按 **Ctrl+O** 或输入 `/sessions`，按时间和首条输入选择以前的对话，**不用填 UUID**。
- 运行中或权限确认中不能切换；取消列表保持当前对话，切换前等待原运行环境完整收尾。
- 已启用项目能力且有来源合格的项目时，首次选择项目名称、填写操作署名，勾选记住；以后这个文件夹的新对话自动关联并重建原记忆索引。多个候选必须明确选择。
- 项目选择不批准 Memory，不自动创建项目、不自动开启未配置的知识功能。复制配置到另一个文件夹不会继承该归属，来源变化会拒绝自动关联。

当前请求协议为 Session 13 / Context 12。旧记录不能直接恢复时，点击 **创建新版数据空间并开始**，程序安排新目录并保存选择，旧记录原样保留。无需自己起目录名，也不迁移旧项目与记忆。退出不选择新目录；保存失败可能留下空的新目录。

需要完整配置时按 **F2**，或运行 `traceh chat --tui --configure`。工作区、数据目录、会话 ID 和环境变量名收在高级设置里。

## 配置执行沙箱

F2 的 **执行沙箱 → 配置执行沙箱** 提供中文表单。需要先准备正在运行的 Docker 和本机已有的
Linux 镜像；配置页不会启动服务或下载镜像。目前只实测 Windows + Docker Desktop + Linux 容器。

- Docker 连接：左侧选择该字段，点 **刷新可选项**，下拉选择本机连接，也可在下方手动填写名称；
  点击 **更新这个值**。不会自动选择第一个连接。切换连接会清空旧镜像，需要重新选择。
- 运行环境：先更新连接，再选择此字段并刷新，下拉显示本机镜像名称和短身份；同一镜像的多个标签合并。
  也可手动填写镜像名称／标签（例如 `my-project-env:dev`，仅为示例）或完整 ID，点击 **更新这个值**。
  系统查询所选 Docker 中的实际镜像并固定完整 `sha256`，不需要用户抄写 hash。下拉项绑定刷新时看到的
  身份；手填标签在更新时解析，保存时按固定身份复核，不随同名标签变化而自动升级。
- 读入与回写范围：按工作区相对路径添加文件或目录；`.` 表示整个工作区，回写范围必须位于读入范围内。
- 资源限制：表单给出可修改的内存、CPU、进程数、执行时限、文件和输出上限，单位显示在标题中。
- 网络当前只支持关闭；工作区不直接挂载，`.git`、`.env*` 等受保护内容不复制，链接和特殊节点拒绝。
- 允许启动外部进程的插件：默认空列表。添加后明确填写已安装插件 ID、精确版本、服务器工作区绝对路径、
  输入总量、每次收发上限和本次激活最多尝试启动几次。失败也消耗尝试次数，不自动重启。
  此授权不会替你启用插件；插件仍需在启动配置中明确启用，自己的 Python 代码仍受信任。

刷新和镜像校验只调用 Docker 的只读查询，不启动服务、不下载／构建镜像，也不运行容器。
查询超时、Docker 不可用、镜像不存在或不符合 Linux／无自动挂载卷要求时，会提示且保留原文件；
空列表可手填已有镜像或准备好环境后刷新。每次查询有 10 秒期限和 1 MiB 输出限制，Esc 取消会等待查询收尾。
这里只核对镜像元数据，Python、项目依赖及 cgroup 资源能力仍在实际执行路径验证。

点击 **校验并保存使用**，再 **应用配置**；保存启动配置后下次可复用。关闭沙箱会让进程命令被拒绝，
不会改成宿主执行。工具改动经过范围及原快照核对后写回，完成验证和固定审阅的临时改动不写回。
Product 固定检查配置中的 `verification.protocol_version` 当前为 2；旧 1 明确拒绝，不能自动迁移。
沙箱文件格式为 2，包含 `format`、`policy`、`plugin_grants`；旧格式 1 明确拒绝，需选择新的配置文件路径再用表单填写保存，
不会自动改写或删除旧文件。普通启动配置文件本身仍为格式 1，两者不是同一份合同。

聊天中输入 **`/sandbox`**，查看当前配置和最近 20 次执行（当前会话的工具/完成验证及宿主应用级插件服务器）：实际 Docker 后端、当时权限与额度、
结束原因、资源收尾、回写状态和回执编号。页面只读，可选择复制，不会调用模型或重跑命令。
只有请求记录时显示“尚未确认”；配置成功、命令 finished 都不等于验证通过。
命令行也可用 `--sandbox-config <保存的文件路径>`；run、chat、resume 和 eval 共用该策略解析器。
eval 要求 `plugin_grants` 为空；应用级共享服务器不属于独立 benchmark attempt，非空会明确拒绝。

## 在聊天里修改并应用

聊天空闲时按 **F2** 或输入 `/settings`：

- 修改模型、地址、密钥或 Context 路径，然后点击 **应用配置**。
- 界面显示收尾过程，旧 ChatDriver、观察者、Product、Runtime 和 Store 关闭后，恢复同一个 Session。
- 下一轮使用新配置，已有对话和此前请求的证据保留。关闭失败时停止切换。
- 临时密钥框始终不显示已有值；同地址、同 Provider、同密钥变量名时留空可保留当前进程密钥。
  更换连接身份或加载另一份启动文件后，需要重填或依赖环境变量。
- “保存配置”保存项目 profile，“保存为个人默认”保存通用连接；**应用不会自动写盘，保存不会立即切换**。

当前请求或权限确认尚未结束时不能打开配置。继续同一会话必须保留原数据目录；已有 Session 的
插件切换仍走 `/plugins use`。要换插件集合或 Product 配置，可清空会话 ID、填写工作区明确新建会话。
取消关闭面板；收尾时再次退出可取消尚未执行的重启意图，但仍等待原操作收尾。

## 配置来源

优先读取个人默认，再由当前目录 `.traceh-tui.json` 覆盖，最后使用显式 CLI 参数。空白连接字段表示
继承，插件栏清空或关闭开关明确表示不启用外部插件。项目 profile 保存 13 个基础字段、4 个可选
压缩字段、3 个可选项目偏好及 5 个可选 token 字段，另含 1 个摘要方式字段，共 26 项；缺少可选字段表示未指定。它不是完整 CLI 参数备份；重试与普通 Chat verifier
仍走原 CLI/项目环境文件，Product 的验证命令可以在任务执行表单里配置。

自动发现的 profile 不会携带旧工作区和旧 Session 到其他目录。数据默认存在当前或显式工作区目录下的 `.traceh`；
明确的项目、CLI 或进程环境存储设置仍有效。个人环境文件的加载范围受到上面列出的限制。
路径在保存时转为绝对路径；加载文件里的相对路径按文件所在目录解释。

需要明确指定启动文件时，仍可以运行（路径为占位示例）：

```powershell
traceh chat --tui --tui-profile "<launch-profile.json>"
traceh chat --tui --configure
```

只有显式指定的 `--tui-profile` 才允许该文件携带会话目标。文件仍严格使用格式 1，不自动迁移。
配置损坏时在配置界面修正；原文件与账本保留。保存先写齐临时文件再替换，取消不会撤销此前已保存的内容。

## 不写 JSON，按功能填写

| 页面 | 填什么、怎么使用 |
|---|---|
| 会话与运行 | 日常用 Ctrl+O 选择会话；高级区可改工作区、会话、数据目录及默认项目偏好；展开已安装插件列表，勾选后点“使用勾选插件”。关闭插件开关不卸载插件。 |
| 知识与记忆 | 点“配置知识与记忆”，展开“知识检索与预算”，分别开启历史原文、Skill 或项目记忆；再填写资源目录、插件身份或来源名称。 |
| 任务执行 | 点“配置任务执行”，填写审批署名、源 Git 仓库、模型、接收结果的 bare Git 仓库及完整目标分支，逐项填写验证命令与参数。 |
| Token 预算 | 明确填写编码、模型窗口、回答预留、安全余量；提前压缩比例留空为输入预算的 80%。本地显示估算，服务实际用量另列。四个核心值全空关闭。 |
| 自动压缩 | 选择沿用、开启或关闭；开启时填写历史触发字节数、摘要字节上限和保留最近轮数。默认规则摘录；可选“模型语义摘要（使用当前连接）”，需填齐 Token 预算并允许至少 2 步。摘要也花费 token。 |

功能表单左边是中文参数目录，展开分组并点击参数，右边显示说明、单位和输入框；填好后点
**更新这个值**。列表先选父项点“添加一项”，再选新项填写；命令及每个参数分别一项，不需要 JSON
括号或额外引号。可选模式用下拉选择。空策略首次开启读取会带入可检查、可修改的预算。

点 **校验并保存使用** 才写入功能文件并选用；取消只丢弃未保存草稿。然后在主配置页点 **保存配置**
记住下次的选择，再点 **启动聊天／应用配置** 生效。关闭功能开关只取消装配，不删除原文件或事件。
新建功能文件默认放在启动 profile 旁边，名称为 `.traceh-context.json` / `.traceh-product.json`；
高级折叠区可以填写已有文件路径。已有文件会先通过原解析器校验再显示，外部修改后要求重新加载。

预设是界面中可见、可编辑的起点。项目来源、插件身份、审批人、接收仓库/分支与命令仍要明确填写；
配置时不会替你创建 Git 仓库、执行命令或批准任务。任务模型必须与聊天连接一致，启用 Memory 和
Product 指向同一来源时，其来源标识与目录也必须一致。高级检索系数和角色权限仍需理解后再修改。

## Skill、Memory 与验证边界

直接在聊天正文或治理证据里鼠标拖选，右键弹出“复制”；**Ctrl+C 只复制选中的文字**，没有选区时
不执行操作。退出使用 **Ctrl+Q**。顶部按钮栏与 F3 独立复制页已删除；没配置 Product 时右侧空面板隐藏。
在聊天主界面按 **Ctrl+B（任务面板）** 可随时展开/收起右侧区域；没配置时也能展开查看“未启用”提示。
已配置 Product 时默认展开，未配置时默认收起。收起不停止任务或状态刷新；审批输入保留，展开后恢复
确认框焦点，不自动提交。详情页/弹窗以及退出收尾期间不切换主面板；显示偏好不跨重启保存。
Windows 直接写系统 Unicode 剪贴板，TUI 内可 Ctrl+V 粘贴；其他平台依赖终端 OSC 52。系统剪贴板被
占用时会提示。复制范围是当前保留的最多 2,000 行显示文字，并非完整会话导出。

空闲时按 **F4** 或输入 `/memory`，从提议下拉框选择实际记录，填写槽位与操作人，
点“审阅批准”。新记忆 ID 可留空自动生成；替换/撤销需要选择已有事实。随后仍需审阅真实正文并输入
`CONFIRM`。取消不会生效；表单不自动批准、不改变项目绑定、不自动重建检索索引。

Context 原始 JSON 编辑器保留在 **高级：文件路径与原始 JSON** 折叠区，普通配置使用上面的中文表单。
预算、资源根、项目来源与内容规则都能逐项填写；关闭开关并应用会关闭该装配，不删除原事件。
项目绑定、Skill 选择、Memory 审批依然经过原治理服务；面板不会安装插件或自动批准权限。

本地校验使用独立环境副本，不影响当前连接，不发出模型请求，也不保证认证/网络/插件激活一定成功。
实际启动和恢复仍走原 Runtime 与协议检查。验证方式见 [当前定向记录](validation-tui-feature-settings.md)；
未跑全量或 L2，不代表发布门禁已完成。

## 完整请求 Token 计量

计量需要 `tokens` 可选依赖，首次加载编码可能下载公开词表。F2 的“Token 预算”页每个值都有中文说明。
CLI 参数为 `--token-encoding`、`--context-window-tokens`、`--context-output-reserve`、
`--context-safety-margin` 和 `--context-trigger-percent`；前四项必须一起填，最后一项留空为 80。
窗口请按实际服务能力填写，编码明确指定；软件不根据任意模型名称猜测。配置页面保存并应用后生效。

输入上限 = 窗口 − 回答预留 − 安全余量。启用 token 模式后，自动压缩按这个输入上限的比例提前触发，
原历史字节触发值不参与判断；摘要字节上限、最近保留轮数仍生效。自动压缩关闭就只计量和拦截超限。
E1 会在后续步骤维护已闭合旧历史，E2 按剩余 token 整块选择合格参考。当前轮工具结果不能拆；仍超限时 E3 在聊天中解释占用和可调整项，保留完整调用/回复并停止该次请求，不自动重跑工具。

状态条显示最近请求的输入估算；Ctrl+X 详情列出分项及服务端实际输入/输出。估算不能保证与远端分词
一致，实际 usage 缺失显示未知。更换编码库版本后核对历史估算可能明确拒绝，不会静默重算成另一个数。
验证见 [E0 专题](validation-request-token-meter.md)、[E2 验证](validation-reference-token-budget.md) 与 [E3 真实旅程](validation-context-acceptance.md)。超限提示定位本次未发送请求；Ctrl+X 仍可展示之前最近已发送请求，两者不能混为一次调用。

D：模型摘要使用同一调用、费用与取消主线；完整 JSON 校验通过才追加历史摘要，原文保留。Ctrl+X 区分“历史语义摘要”和“对话”请求，失败给出依赖设置提示。配置字段 `auto_compact_method` 可为 `extractive` 或 `semantic`，空表示默认摘录。详见 [D 验证](validation-semantic-summary.md)。
