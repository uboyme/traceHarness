# ADR-0052：配置一次，工作区启动复用

状态：接受。日期：2026-09-08。

## 问题与决定

交互入口此前无条件打开完整配置，用户需要理解数据路径、Session ID 和项目关联。保留现有 CLI、Session、项目权限与收尾主线，改变默认交互路径。

1. 裸 `traceh` 对已保存的连接进行私有环境预检查，通过后直接进入新聊天；首次缺连接用简短向导，`--configure` 和 F2 显式进入完整配置。预检查结果不能把高级环境参数固化为下一次显式输入。
2. 服务地址来自用户明确选择的官方服务/地区预设，自定义地址仍显式填写；有限模型快捷项可选或自行输入，不暗选模型，不声称账号开通或网络认证已验证。
3. 首次保存个人连接可选择 Windows 当前用户 DPAPI 加密存储密钥。加密身份和熵包含 exact provider/base_url/api_key_env；环境凭据先于加密存储，启动文件和事件无明文密钥。其他系统保持既有环境凭据；不添加明文兜底或额外依赖。进程内明确输入与解析出的存储密钥区分，F2 换环境文件可以重新解析凭据。
4. 对话列表只投影同工作区、当前协议、非 managed Agent 的 Session；选择后复核，通过原 RestartChat→Drain→open_chat_session 切换。取消不切换，未收尾不启动后继 Runtime，无独立会话索引或默认自动续聊。
5. 工作区项目偏好只在首次人工选择项目、署名并勾选记住后保存。三个可选 profile 字段为 default_project_id、project_actor_id、project_workspace；新会话必须重新通过原 source resolver 与 bind_session/CAS，正式项目和 Memory 事件仍是唯一权限事实源。已有会话使用原正式归属，索引失败后恢复只补建派生索引。没有默认项目、自动创建项目或自动批准 Memory。
6. 旧数据只读辨认后提供明确按钮创建新的独占数据目录，并保存新启动目标；旧数据不移动、不删除、不迁移。诊断不代替 Store/Session 的完整验证。取消不选择新目录；保存失败可能留下新建的空目录，不删除它猜测回滚。

Session 10 / Context 9 和底层持久协议不变。format-1 启动 profile 在原 13 个基础字段和 4 个可选压缩字段上增加 3 个可选项目偏好；保存写齐 20 项，缺可选项表示未指定，未知字段和版本仍拒绝。密钥文件与启动文件分别原子保存，不承诺跨文件事务。

## 验证

见 [简化启动验证](../validation-tui-simple-start.md)。验证使用真实本地 HTTP、生产 Runtime/SQLite、Windows 合成密钥 DPAPI 和真实隔离 Git；不使用用户真实密钥，不执行全量、L2 或发布门禁。
