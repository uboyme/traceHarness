# 有界源码读取：实现与真实对照合同

日期：2026-09-11。用户授权：只改阅读能力，模型、预算、委派说明不变；只跑相关检查和同条件真实小样，不跑全量或 L2–L4，不提交、发行或启动其他阶段。

## 1. 根因与 owner

上轮调查方只有 `read_file(path)` 整文件正文和 `search_text` 匹配行；缺少行号、范围和可执行续读。四个真实助手读取了源码但用尽累计预算，不能归因成接口没有装配，也不能保证补阅读后会自主委派。

本阶段修改公共 `tools/builtins/read_file.py` 与其页渲染 helper，以及 `search_text` 的阅读导航说明。路径仍由 `resolve_workspace_path` 与原 Workspace policy 验证；结果仍经原 ToolRuntime、Effect/Session、Composition 和 Frozen Request。没有新缓存、索引、预算账本或长期文件事实源。

## 2. 读取合同

- 同一 `read_file` 接受必填 path；可选 start_line、end_line（1-based，闭区间），以及续读用的 start_column（1-based Unicode 字符）和 source_sha256。未填起点为第一行，未填终点为文件末尾；输出最多 120 行、8000 个序列化 JSON 字符。此为通用模型视图限额，不是 Token 费用上限。
- 输出统一为带 format/path/source_sha256 的 JSON 视图，正文有真实行号，明确范围是否完成、是否到文件末尾、是否截断，以及下一次完整 `next_read` 参数。路径单独读取也使用同一分页主线，不保留整文件旧模式。
- 长行允许在同一行内前进，不能永远返回同一段或静默丢弃尾部。空文件明确返回空视图；非法范围、错误类型、无效编码、目录、越界路径、变化后的摘要均明确失败。
- 摘要绑定本次实际读取的原文件字节；模型持旧摘要续读时，必须重新校验。它是变化检测，不授予路径权限，也不是历史文件快照库。读取仍扫描当前文件，不宣称磁盘 I/O 或文件大小常量有界。
- 读/渲染在工具拥有的线程工作中完成；取消必须等待该工作结束并关闭文件，保留取消外层语义。不会在 AgentLoop 新增阅读状态机。
- `search_text` 保留当前匹配算法和输出，说明命中后用同一文件的 start_line/end_line 阅读附近逻辑；不在本阶段改检索排名、关键词、委派说明或收尾策略。
