# 有界源码读取：范围能力已接入，协作收益仍未证明

日期：2026-09-11。按用户授权实现公共阅读能力，并做相同材料的真实对照；不改模型、预算、委派说明、AgentLoop 或评分，不提交或发行。[冻结合同](../plan/TRACEHARNESS_BOUNDED_SOURCE_READING_CONTRACT.md)。

## 1. 做了什么，为什么

上轮真实诊断发现：助手有工具、确实读过源码，但 `read_file(path)` 只能整文件读取，没有真实行号或可执行的范围阅读。说明文字让它“读相关范围”并不能补上这个能力。

本轮只修改公共 [`read_file.py`](../../src/traceh/tools/builtins/read_file.py)、新增同层 [`file_page.py`](../../src/traceh/tools/builtins/file_page.py)，以及 [`search_text.py`](../../src/traceh/tools/builtins/search_text.py) 的阅读导航说明。没有新缓存、索引、状态机、预算账户、评估器或插件入口；所有装配使用同一个内置读文件工具。

- 同一 `read_file` 接受 path、可选 start_line/end_line；行号从 1 开始，包含两端。只填 path 也是第一页，不保留旧整文件模式。
- 统一 JSON 视图含真实行号、总行数、来源摘要、实际起止位置、truncated、eof 和完整 next_read 参数；最多 120 行、8000 个序列化 JSON 字符。
- 长行通过 start_column 连续读取；生成的 next_read 带 source_sha256，文件中途变化时明确拒绝旧续读。手工不带摘要的范围请求是对当前文件的新读取，不声称它属于旧版本。
- 搜索匹配算法和结果不变，说明命中后可按行查看附近正文。调查方仍不获得 shell/read_tool_output。
- 原路径 owner 每次校验工作区边界；线程读取/渲染由工具拥有，取消等待工作收敛，保留外层取消和底层失败。结果照常写入原 Effect/Session 并进入 Frozen Request。

举例（仅为示例）：搜索命中 `module.py:320` 后，可以读取 310～345 行。页没读完就照 next_read 继续，不能把“这一页结束”当成“文件结束”。文件变化会拒绝带旧摘要的续读，避免静默拼接两个版本。

这是模型输入视图有界，不是任意文件的磁盘或内存有界：内部仍读取当前完整文件。字符数也不冒充 Token 预算，实际费用继续由原 Provider usage 与预算账本记录。

## 3. 格式通过不等于回答正确

结构通过 **4/6 → 5/6**；原 Verifier 只检查未改源码、输出格式和引用范围存在，评分器没有被改写。

本助手逐份核读原 CAS 补丁与冻结源码，五份格式通过的复杂答复均有关键误判。此为 **Codex 源码审阅，未经用户人工金标确认**，不回写原评分：

| 答复 | 核实的问题 |
|---|---|
| 原版明确第 2 次 | 把 close_account 的 pending 检查当保留收尾额度，把事件提交当产物捕获；引用多处不支持结论 |
| 原版自然第 2 次 | 把墙钟预留当独立清理额度，把 usage settlement 当产物捕获 |
| 新版明确第 2 次 | authority 的部分引用准确，但用 reserve_child 的函数声明代替正文分析，仍混淆保留额度和产物捕获 |
| 新版自然第 1 次 | 把 grant_root 当保留额度，把 run_turn 返回 TurnResult 当产物捕获 |
| 新版自然第 2 次 | 已引用 retained_tokens 参数，仍把取消收敛辅助函数当额度保留，把 collect/report 当产物捕获 |

实际代码中：`reserve_child` 将 retained_tokens 交给原 Projector 容量准入；Workflow 在主方整树 dispose 后调用原 capture；调查创建禁止父历史继承，工作区绑定原 source/base revision。原源码摘录、补丁摘要及逐题判断见[源码审阅](../validation-data/dynamic-collaboration/bounded-reading/source-review.json)。四份简单题的实际版本通过原确定性验证；其余三个复杂试次是硬失败。

可观察的共性是：**接口有了，模型仍可能只看函数声明或局部片段，就推断职责；助手也没有稳定在额度内交付。** 不能据此把某个业务字段名硬编码进通用提示。本轮保留通用阅读功能，不声称自主协作或语义正确性已经改善；默认仍是 single，预算收尾策略留待单独授权。
