# ADR-0060：按失败请求的原证据解释上下文超限

状态：E3 已实现并通过定向、反向与真实验收，2026-09-09。沿用 E0–E2；不增加重试、压缩或权限 owner。

RequestBuilder 在原 token-measurement 已收敛写入后抛出具名错误，并携带 Session/Turn/Step 身份。
身份只定位原事件，不复制计数、请求或上下文成为第二事实源。ChatDriver 的失败路径通过原
validate_token_measurements 复核账本，派生只读 ContextPressureView；不能把后续 Turn 的计数错配到前次失败。

Line 与 TUI 共用固定宿主文案，展示估算输入/额度/输出预留/安全余量、完整分项、本轮成功维护次数与
维护失败次数、本次参考 token 排除数。摘要请求超限单独标识；不打印原问题、工具参数、结果或异常正文。
计量器不可取得、来源证明失败或诊断读失败时保留原失败，只显示“明细无法核对”，不编造零占用。
取消仍沿原 Runtime 收敛，诊断读取的取消不能被宽泛异常捕获吞掉。

提示缩短输入、按实际模型容量调整 Token 配置、使用新一轮读具体片段或新会话。
不自动重跑已执行工具、不切割当前 Tool 组，不承诺自动压缩任何大小的新输入或 Provider 隐藏模板。
真实整合验收使用隔离 Session/Workspace 和现有授权配置，含语义摘要、原文读回、大结果搜索、换题、重启、
成功/非零退出、真实响应交付前重复取消以及本地硬拒绝。费用按真实 usage 和未知计费边界分别报告。
