# 保留工具输出：显式真实模型验收

本目录不由 pytest 自动执行。需要显式授权调用模型后才运行：

```powershell
python tests/live_tool_outputs/run.py --profile <已有启动配置文件> --output <全新的证据目录>
```

路径占位符是调用者输入，不是产品默认。密钥只经过现有配置加载器或 Windows 凭据读取器，
不会写到报告。脚本复用正式 Provider、Runtime、Tool、SQLite、History、压缩和请求重放主线。

合成子进程执行时才生成随机观测；脚本源码不含答案。模型按自然问题执行一次诊断、自己寻找
预览之外的记录，然后在压缩/重启后回答另一条记录，最后切换话题。分别测试进程 exit 0 和 7。
只允许临时工作区读取、执行一次指定诊断与本会话历史/输出读取，不改变真实项目或用户会话。

脚本断言答案包含实际已保存的两个随机字段，实际发生输出读取，压缩后实际查询来源目录，
执行计数为一，请求重放与完整来源不变量通过。报告保留失败；每次运行使用新目录，不覆盖证据。
模拟模型的定向测试位于 `tests/test_retained_tool_output.py`，不能代替本脚本。

验收脚本显式设置 Provider 每次超时 45 秒、原 retry policy 最多 6 次/360 秒；这是隔离测试配置，
不会改用户启动设置。TLS/网络错误与来源/答案失败分开报告，不跳过断言，不放宽页预算。


## B+ 关键词查找模式

```powershell
python tests/live_tool_outputs/run.py --profile <已有启动配置文件> --output <全新的证据目录> --keyword-search
```

此模式构造 260 个多行记录，标题与随机字段之间有采样行；命中附近可能出现上一条记录的字段。
问题只描述要找的记录，不教模型使用工具。脚本要求先搜索再读取，核对随机答案；压缩重启后
重复验证，并测试两个重复标记、无命中以及新话题。每个 exit 场景只执行原程序一次。
普通 B 模式允许通过搜索片段或分页取得足够证据；B+ 模式明确要求搜索后实际展开。
搜索调用参数、命中页、读回位置、答案、重放和不变量检查写入报告；失败运行不覆盖。
