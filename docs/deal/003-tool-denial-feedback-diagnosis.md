# 工具拒绝反馈的真实对照

本轮是用户授权的来源选择/拒绝反馈诊断，不是 AR-D 发布验收。问题、种子和命令是显式夹具，不是产品默认。

## 1. 已核对的责任边界

上一轮只读扫描 grid-05 候选和两组输出实验，共 120 条任务：14 条发生拒绝、共 83 次。
有下一次请求的 78 次，原拒绝说明全部送达，工具也仍列在该次请求中。
账本记录 status、error_type 和 policy；当前 surface_message 只把 content 投影为模型工具消息。
默认 Continuation 不接收工具结果的拒绝分类：模型继续发调用时继续，达到 Step 限额停止。
真实重复轨迹中的调用 ID 和 Step 不同，不是宿主自动重试同一工具执行。

SourceOnly 是冻结评测的权限条件，拒绝工作区读取但工具定义仍可见。不能把“一次参数被拒绝”自动等同于工具永久不可用，
也不能调用有状态的 Policy.check 来推测工具列表；该评测的 setup shell 检查会认领一次准备执行。

## 2. 单变量候选

仅在隔离源码中试改 session/surface_replacement.py 的 denied 工具消息：用原事件字段生成 JSON，
包含 status、error_type、reason 和 policy。不给新权限，不推断 retryable，不硬编码替代工具或答案。
非 denied 的消息、工具表、系统提示、Context 包装、预算、题目、模型和来源权限不变。
生产事件和协议不改；候选请求必须用候选冻结源码重放，不能把实验读法作为旧协议的隐式兼容。

每臂 8 条：三个种子的输出附近读取题与英文 Skill 题，加两条正常读取对照。属于已知问题的小样本探索，未声称留出集。
源码、运行器和实际语料在调用前冻结；不在运行中调提示词或删失败题。

## 3. 运行器问题与修复

[03 轮](../validation-data/active-retrieval/ar-e-denial-03/summary.json)发现诊断入口未将相对输出目录转换为绝对路径，
两边各 4 条 Skill 准备在 SkillResourceRoot 处报 skill-root-binding-invalid，尚未调用模型，不计有效完整对照。
两边各 4 条输出任务实际运行，全部保留，独立重开 8 个会话、50 个请求，重放和不变量通过。
这轮服务报告 246826 total_tokens，50 个结束 Attempt，未知和估计用量均为 0。

修复 tests/live_active_retrieval/output_diagnosis.py：与原 grid 入口一致，对输出目录调用 resolve()。
没有改变 Skill 根目录合同、用户数据或生产默认。新增相对/绝对路径的真实 SkillResourceRoot 合同检查，
以及源码不匹配时加载 Provider 前拒绝的检查。隔离加载旧运行器后，相对路径检查在预期的根目录合同处失败；
恢复正确运行器则通过，不把导入失败当作反向验证。

## 4. 完整重测结果

[04 轮完整结果](../validation-data/active-retrieval/ar-e-denial-04/summary.json)：同材料、同预算、同候选，全部重新运行。

| 指标 | 原版 | 结构化拒绝候选 |
|---|---:|---:|
| 有证据且回答所问事实 | 4/8 | 5/8 |
| 被拒调用总数 | 23 | 8 |
| 同任务中相同工具/参数的重复拒绝次数（首个不计） | 12 | 0 |
| 耗尽步骤的任务 | 1 | 0 |
| 完整请求独立重放 | 51 | 36 |
| 服务报告 total_tokens | 257524 | 169104 |

16 条任务没有运行错误；87 个请求独立重放，无不变量/重放错误和未结束 Attempt。
87 个结束 Attempt，426628 total_tokens，未知/估计均为 0。输出任务原命令每条实际执行一次。
候选有后续请求的 8 次拒绝均核对了结构化内容实际进入成功模型请求；被拒工具仍可见，没有靠删工具消除重复。
正常的两条对照双方都通过，但没有收到拒绝，所以这些对照本身不能证明候选格式的效果。

三条输出附近读取题双方仍全失败：模型少重复了，却依然没有转向原输出搜索，常直接回答缺少资料。
额外答对的是一条英文 Skill 题。部分任务在首次拒绝发生前就出现工具选择差异，不能把全部差值归因于反馈字段。

**决定：保留实验候选，暂不合入生产。** 重复减少是有价值的探索信号，不等于来源选择已修好。
下一步应固定同一个拒绝后的请求做单步成对对照，比较修正行动、原样重复和提前放弃；不改原评分题或放宽门槛。
若以后采纳，应单独完成模型消息投影的协议冻结、重放与预算回归，不直接改旧协议的 renderer。
