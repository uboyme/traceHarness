# E 后语义检索有界复测合同

2026-09-09，评分前冻结。用户已授权真实复测并要求达标才加入；E1/E2/E3 已完成，见各阶段验证。

## 1. 保留门槛与原生产主线

不改 `benchmarks/retrieval_v1/corpus.json`、原 11 题、K、判断或阈值；八条中英文改写原样来自
`tests/local_retrieval_screen/cases.json`。所有 acceptance 数字原样复用：原非语义零退化、原语义
Recall/MRR/precision 均 1，中英文分别 Recall/precision 至少 .75，九题语义 Recall 增益至少 .25，
隔离违规 0，暖查询 p95≤500ms、冷加载及重建各≤120s、活跃资产≤256MiB、float32 向量≤4096 bytes/项。

重新通过原 Runtime 捕获合格 Skill 顶层元数据和当前已批准 Memory 的 canonical corpus。
保留原词法准入；只有词法为空且无完整字面锚点时补语义候选，不编码隐藏正文或外项目/撤销/被替代资料。
新增题是离线可行性评估，不冒充真实 Runtime dispatch。筛查结果不写进 Session 或伪造生产收据。

仅下载以下两个发布者官方固定 revision 的 config/tokenizer/vocab 与 safetensors，在新隔离测试目录保存。
下载前读取文件大小及 LFS SHA；下载后逐文件摘要冻结。无需安装新推理依赖，不运行远程代码。

## 3. 有界九个候选

比较中文模型单独、英文模型单独、逐文档取两个 cosine 的最大值三种固定合并方式；各自阈值 .6/.7/.8，
共九个候选，分数降序、原 block identity 解同分，再复用原 K 与实际字节准入。没有可学习路由或人工指定某题该用哪模型。
双模型分数没有天然校准，因此这只是明确假设，仍须过同一质量门槛；不能因性能好或中文改善就跳过英文精度。
阈值范围基于官方对 BGE 分数分布的说明在评分前选定，不看本次分数后重新调参。

原旧 C3 的“仅本地资产、不下载”是那次已完成筛查的边界。本次新授权允许上述有界公开资产下载，
不修改旧合同或旧结果；仍不调用外部向量服务，不加载用户密钥。multilingual-e5 的标准资产较大且
当前环境没有 ONNX runtime，本次不扩展安装/量化流水线，不无限试模型。

## 4. 停止与接入

在模型评分前冻结本合同、当前源码/测试/原语料/捕获和全部资产摘要、运行库版本；之后不更改判断、阈值或合并方式。
记录每个候选的 19 题评分、5 次暖计时、未知 token、重建一致性、实际大小和失败。网络失败不能伪称质量失败。
全部不通过则保留测量证据并保持语义关闭；通过者还需原 Runtime 接入合同、资格证明、索引可重建、
失败/取消/所有权/重放与真实 Provider 阅读验证，才可启用。向量永远只是可重建派生数据。
若多个候选通过，先选中英文平均 precision 较高者，再选 encoder 较少者，再按暖查询 p95 较低者；
仍相同时取候选 ID 字典序。该顺序也在本次评分前冻结，不以模型名称或某题得分指定赢家。
不跑全量/L2–L4/发布或安装长门禁，不提交、推送或发版。
