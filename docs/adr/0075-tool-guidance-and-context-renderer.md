# ADR-0075：工具说明与当前能力一致

2026-09-13，已采纳。用户授权修复记录 060 暴露的工具导航与分页说明问题。

工具清单已随实际请求提供，但 Context 的固定导航及 Patch 工具说明又点名推荐未必装配的输出工具。Patch 的 count/offset 只声明整数，未说明字符单位、默认值与范围，模型连续取极小页后耗尽预算。

通用导航不再写死检索或输出工具名称，指向当前请求提供的工具及参数；来源 hit 的 read_action 也必须核对当前工具列表，导航不授予权限。Patch 工具明确 Unicode 字符单位、默认 2000、最大 4000、零基 offset 和 next_offset/null 结束条件，建议首次只传 artifact_id。原读取实现与 schema 共用既有数值常量；权限不变，不自动注入新工具，不强制模型步数或页大小。

原文若被保留，只使用当时提供的输出读取能力，或在同一 offset 请求较小页；无法获取正文应报告限制。正文可见性、身份、完整区间覆盖与显式整合仍由原 owner 核验，预览不能代替全文。

Context 导航是确定性 renderer 和字节预算的一部分。修改它会改变重建请求，因此唯一当前协议切为 Session 15 / Context 13 / context-json-v13；策略 v8、SQLite 2、request/view 1 不变。新实现明确拒绝旧 Session/Context，不迁移、删除、重写旧日志，也不增加兼容 renderer。旧验收事实保留，由对应源码核验；本次新请求的冻结、字节计量和重放必须一致。

本轮不修改模型、Provider、Supervisor、预算、工作区、审批或 Promotion，不追加真实模型验收。
