# ADR-0074：主方自主侦察，以职责交接为边界

2026-09-13，已采纳。依据用户明确要求，替代 ADR-0070/0071 中固定两步侦察、单工具批次与独占一次规划尝试；保留其 single/multi、必经一个助手及原所有权合同。

记录 059 的真实运行在一次读取三个文件时被整批拒绝，随后工具表切换而提前失败。这证明旧规则限制了正常信息获取，不能据此判断模型编码能力。主方应自行理解需求、选择调查深度，再确定互补职责。

准备期间同时提供原只读工具和 submit_collaboration_plan，保留原会话可见历史，不限制每轮只读工具数量或侦察轮数；总步骤、调用、Token、时间和重复拒绝规则照常执行。准备期间没有实施工具。分工字段表达目标、范围、排除项、交付物、简报和主方如何使用结果，不指定每一步动作。

原 ToolRuntime 的参数拒绝、明确未执行的工具拒绝，以及分工工具在 delegate 前的字段校验失败可修正。原 Session 结果区分这些情况；成功、未知或已进入派发的失败不允许再次派发。一次批次中的多个分工请求全部在派发前拒绝。没有第二账本或可变重试标记。

取得完整助手交接后，由原事件切换实施工具并隐藏委派工具。主方仍必须读取并显式整合可写助手的 Patch，通过原完成检查及独立 Product 验证；人工 Promotion 不变。助手权限、工作区隔离、取消清理与总预算均未扩大。协议版本不变，原请求按原冻结视图重放；新请求使用自主准备视图。

自由度不等于成功保证：主方可能调查过久或分工不佳；总上限到达仍停止，不能把无分工的纯文本当作完成。真实模型效果必须另用一次冻结验收证明，不能从脚本测试推断。
