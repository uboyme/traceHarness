## 第二项：已能纠正，不等于完成交付

主方首次分工 schema 错误后自行改正，只启动一个助手；1653 字节 Patch 一次读完并显式整合。旧命令 invoice-check --version 只调用一次，真实 start-failed 回执包含 FileNotFoundError；主方随后改用 Python，无安装或宿主回退。
